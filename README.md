# Asma Zaheer — Luxury Beauty Portfolio

Mobile-first media kit for [@itsasmazaheer](https://www.tiktok.com/@itsasmazaheer). Next.js App Router, Tailwind, Lucide, Framer Motion.

## Run

```bash
cp .env.example .env.local
# add RESEND_API_KEY
npm install
npm run dev
```

Swap placeholder files in `public/images/`, `public/videos/`, and `public/media-kit.pdf`. Update copy and metrics in `data/stats.json` and `data/portfolio.json`.

## Checks

```bash
npx tsc --noEmit
npm run build
```
